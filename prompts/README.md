# 📚 AIプロンプトライブラリ

毎日のリサーチで集めた「本当に使えるプロンプト」を蓄積するライブラリです。

## フォルダ構成

| ファイル | 内容 |
|---------|------|
| `business.md` | 営業・提案・メール・MTG系 |
| `content.md` | SNS投稿・ブログ・コピーライティング系 |
| `automation.md` | 業務自動化・ワークフロー設計系 |
| `analysis.md` | データ分析・リサーチ・競合調査系 |
| `income.md` | 収益化・ビジネスアイデア立案系 |
| `daily-log.md` | デイリーリサーチで発見したプロンプトの日次ログ |

## 使い方

- 各ファイルを開いてコピペするだけで即使用可能
- モデル推奨（Claude / GPT）を明記
- 難易度と効果の目安を★で表示
