## Claude×自動収入アフィリエイト（2026年8月 追加）

> 出典：X @risu_aiafi — 月85万円の自動収入を構築した実践者のプロンプト集

### 継続報酬型アフィ案件リサーチ
**用途：** サブスク・SaaS系の"積み上がる"案件を発掘する  
**効果：** ★★★

```
あなたは継続報酬型アフィリエイトの専門リサーチャーです。

以下の条件で「継続報酬型」の案件を20個抽出してください。

1. 月額課金型のサービス(SaaS/サブスク/オンライン学習)
2. 1件あたりのLTV(生涯価値)が6,000円以上
3. 平均継続期間が6ヶ月以上
4. 解約率が20%以下
5. 発信者の競合がまだ少ないジャンル

各案件について、以下を表形式で:
・サービス名
・月額単価
・継続報酬率
・想定継続月数
・LTV試算
・掲載ASP
・想定検索キーワード3つ
・記事の切り口3案

同じジャンルに偏らないよう、最低4カテゴリーに分けて出してください。
```

### ストック型（腐らない）アフィ記事生成
**用途：** 半年〜1年後も検索され続ける"資産型"記事を書く  
**効果：** ★★★

```
あなたは経験10年のアフィリエイトライターです。

以下の案件について、
"半年後・1年後も検索され続ける"ストック型の
比較記事を書いてください。

案件：[案件名]
想定ターゲット：[年齢/職業/家族構成]
想定キーワード：[メインキーワード]

ストック型の要件：
・時事性を持つ言葉("2026年最新"等)を使わない
・「今月」「今週」等の時間限定表現を排除
・普遍的な"選び方の基準"を軸にする
・比較対象を4〜7個並べる
・体験談ベースの語り口

構成：
1. 悩みの言語化（時代性なし）
2. この分野の選び方3基準
3. 比較表（4〜7商品）
4. 商品ごとのメリット/デメリット
5. 用途別のおすすめ
6. まとめ＋LINE誘導

分量：3,000字前後

ルール：
・「絶対」「必ず」「誰でも」の断定は禁止
・「」以外の記号強調は使わない
・体温を出す1人称の1文を必ず入れる

マークダウン形式で全文出力してください。
```

### LINEステップ配信 自動成約設計
**用途：** 登録→7日で成約する5通のステップ配信を一括生成  
**効果：** ★★★

```
あなたはLINE公式アカウントの
ステップ配信設計の専門家です。

以下の案件に対して、
「登録→7日後に成約」までの
5通のステップ配信を作ってください。

案件：[案件名]
LTV：[生涯価値]
ターゲット：[属性]

配信構成：
1通目（即配信）：登録の御礼＋プレゼント
2通目（翌日）：読者の悩みへの共感
3通目（3日目）：解決策の提示＋成功事例
4通目（5日目）：案件の詳細＋デメリットも正直に
5通目（7日目）：背中を押す＋期限訴求

各配信のルール：
・1通500字以内
・押し売り感を消す
・体験談ベースの語り口
・行動を促す1文を末尾に配置

「7日以内にLINE登録者の10%が成約する」ことを
目標とした設計にしてください。
```
