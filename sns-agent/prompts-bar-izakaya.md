# 🍶 バー・居酒屋特化 Instagram投稿生成プロンプト集

---

## 【投稿タイプ別】生成プロンプト

### 1. 料理・ドリンク紹介（最もエンゲージメントが取れる）

```
あなたはバー・居酒屋専門のSNSライターです。
以下の条件でInstagram投稿キャプションを作成してください。

【店舗情報】
- 店名：
- コンセプト：
- ターゲット：（例：20〜30代のカップル・仕事帰りのサラリーマン等）

【今回の投稿内容】
- 紹介するもの：（例：季節限定カクテル「桃とジャスミン」）
- 特徴・こだわり：
- 価格（任意）：

【出力条件】
- 200〜250字
- 1行目：思わず止まるひと言（感情・情景・驚き）
- 絵文字：3〜5個（やりすぎない）
- ハッシュタグ：15個（地名＋業態＋雰囲気系を混ぜる）
- 最後にCTA：「詳細はプロフのリンクから」or「ご予約はDMまで」
```

---

### 2. 雰囲気・空間紹介（フォロワー獲得に強い）

```
バー・居酒屋の「来たくなる雰囲気」を伝えるInstagramキャプションを作成してください。

【店舗情報】
- 店名：
- 雰囲気を表す言葉3つ：（例：大人っぽい・落ち着く・非日常）
- どんな時間を過ごしてほしいか：

【出力条件】
- 180〜220字
- 「〇〇な夜に」「仕事終わりに」など情景から始める
- 読んだ人が「行ってみたい」と思う言葉選び
- ハッシュタグ15個（#バー #隠れ家 #大人の時間 など）
```

---

### 3. 限定・イベント告知（集客に直結）

```
期間限定メニューまたはイベントの告知投稿を作成してください。

【告知内容】
- 内容：
- 期間：
- 料金：
- 予約要否：

【出力条件】
- 冒頭に「【期間限定】」「【イベント開催】」などの角括弧タグ
- 日時・料金・予約方法を明確に
- 締め切り感・希少感を演出
- 200字以内（読みやすく簡潔に）
- ハッシュタグ10個
```

---

### 4. スタッフ・オーナー紹介（信頼・親近感を上げる）

```
バー・居酒屋のスタッフまたはオーナーを紹介するInstagram投稿を作成してください。

【情報】
- 紹介する人：
- エピソード・こだわり・一言：
- お店への想い（任意）：

【出力条件】
- 温かみのある話し言葉
- 「このお店に来てみたい」と思わせる
- 180〜220字
- ハッシュタグ10個
```

---

### 5. 共感・ライフスタイル投稿（リーチ拡大に強い）

```
お酒・夜・大人の時間をテーマにした「共感型」投稿を作成してください。
商品の紹介は不要。読者の感情に寄り添う内容にする。

【テーマ例（どれか選んで）】
- 仕事終わりの一杯の価値
- 友人と飲む夜の特別感
- 一人飲みの楽しさ
- 週末前夜の解放感

【出力条件】
- 詩的・情緒的な文体
- 150〜200字
- ハッシュタグ：#バー #夜の時間 #大人の時間 など雰囲気系15個
- 最後に店名をさりげなく入れる
```

## コンテンツカレンダー（月8投稿の黄金比）

```
月8投稿の推奨バランス：

1. 料理・ドリンク紹介 × 3
2. 雰囲気・空間紹介 × 2
3. 限定・イベント告知 × 1
4. 共感・ライフスタイル × 1
5. スタッフ・オーナー紹介 × 1

投稿曜日のベスト：
- 木曜夜（週末を意識し始める）
- 金曜昼（週末の予定を探す）
- 日曜夜（来週を前に気分転換）

NGなタイミング：
- 月曜朝（誰も飲みに行く気分ではない）
```
