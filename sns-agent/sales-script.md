## 初回ヒアリングの流れ（30分）

```
0:00〜5:00   自己紹介・アイスブレイク
5:00〜15:00  ヒアリング（現状の悩み・目標を聞く）
15:00〜20:00 サービス説明（解決できる点を伝える）
20:00〜25:00 料金・プラン提案
25:00〜30:00 次のステップ確認（無料お試し or 契約）
```

**ヒアリングで必ず聞くこと：**
1. 今SNSにどれくらい時間をかけているか
2. 一番困っていること（フォロワーが増えない/投稿が続かない等）
3. SNSで達成したいこと（集客/認知/ブランディング）
4. 月いくらくらいなら投資できるか（予算感）
