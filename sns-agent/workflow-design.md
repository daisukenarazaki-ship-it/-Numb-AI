# ⚙️ 投稿生成ワークフロー設計書

SNS運用代行の核となる「AI投稿生成フロー」の設計ドキュメント。

---

## 全体フロー概要

```
クライアントヒアリング
        ↓
月次コンテンツカレンダー作成（AI支援）
        ↓
投稿テキスト生成（Claude/GPT API）
        ↓
画像生成・選定（Midjourney/素材サイト）
        ↓
クライアント確認・承認
        ↓
予約投稿（Buffer/Later等）
        ↓
数値分析（週次/月次）
        ↓
改善レポート納品
```

---

## Step 1：ヒアリングシート（初回）

クライアントから収集する情報：

```
【基本情報】
- 業種・サービス内容
- ターゲット顧客（年齢・性別・悩み）
- 競合・参考にしたいアカウント

【トーン・世界観】
- ブランドのイメージ（言葉で3つ）
- 使ってほしい言葉・使ってほしくない言葉
- 参考にしたい投稿例（URL）

【運用方針】
- 投稿頻度の希望
- 力を入れたいプラットフォーム
- 今困っていること・伸ばしたいこと

【数値目標】
- 3ヶ月後のフォロワー目標
- 最も重視するKPI（認知/集客/売上）
```

---

## Step 2：コンテンツカレンダー生成プロンプト

**毎月1日に実行する**

```
あなたはSNSマーケターです。
以下のクライアント情報をもとに、今月のコンテンツカレンダーを作成してください。

【クライアント情報】
（ヒアリングシートの内容を貼り付け）

【今月の投稿数】
- X：8投稿
- Instagram：8投稿

【出力形式】
日付 | プラットフォーム | テーマ | 投稿タイプ（情報/エンタメ/告知/共感）
を表形式で出力してください。

※ 4:3:2:1の比率で（情報40%・共感30%・エンタメ20%・告知10%）
```

---

## Step 3：投稿テキスト生成プロンプト

**各投稿を生成するテンプレート**

```
あなたは【業種】専門のSNSライターです。
以下の条件で投稿テキストを作成してください。

【クライアント基本情報】
- 業種：
- ターゲット：
- トーン：
- NGワード：

【今回の投稿】
- プラットフォーム：X / Instagram / TikTok
- テーマ：
- 投稿タイプ：情報 / 共感 / エンタメ / 告知

【プラットフォーム別条件】
（Xの場合）
- 140字以内
- 冒頭1行でフック
- ハッシュタグ2〜3個

（Instagramの場合）
- 200〜300字
- 絵文字あり（3〜5個）
- 最後にCTA
- ハッシュタグ10〜15個

（TikTokの場合）
- 台本形式（60秒想定）
- 冒頭3秒のフック必須
- 字幕テキストとして使えるよう句読点で区切る
```

## 自動化ツール構成（Make.com推奨）

```
[Notion/スプレッドシート] コンテンツカレンダー入力
        ↓
[Make.com] スケジュールトリガー（投稿3日前）
        ↓
[Claude API] テキスト生成
        ↓
[Slack/LINE] クライアントに確認依頼
        ↓
承認後 → [Buffer/Later] 予約投稿
```

**実装優先度：**
1. まず手動でフロー全体を回す（ツール不要）
2. 月3社以上になったらMakeで自動化
3. 月10社超えたらAPI直接連携に移行
